Local and Global Variables

Let's talk about local and global variables. Why might it be best to declare the object in the script tag?

If an object is declared inside a function using let or const, it is normally only accessible inside that function. Trying to access it outside the function will cause a ReferenceError.

Declaring an object outside a function allows multiple functions to access it. This is useful when several buttons need to interact with the same object.

However, global variables can cause naming conflicts. Keeping variables inside functions or using a shared object in a controlled scope is often better for larger projects.
