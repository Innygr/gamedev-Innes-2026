t1a14 — Class Extensions by Innes

Inheritance lets a new class reuse properties and methods from an existing class. Here, myCat extends myAnimal.

Example class code

class myAnimal {
  constructor(passName, passAge) {
    this.myName = passName;
    this.myAge = passAge;
  }

  myShow() {
    // Display this animal's name and age
  }
}

Example extending class code

The cat inherits the name and age properties, then overrides myShow() with cat-specific output.
