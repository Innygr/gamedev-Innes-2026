t1a09 — Functions by Innes

Functions organize code into reusable blocks. A function can receive information through parameters, perform an action, and return a result.

Reference: JavaScript Functions

Example function

function myAddNumbers(myIn01, myIn02) {
  const mySum = myIn01 + myIn02;
  return mySum;
}

const myAnswer = myAddNumbers(3, 6);

myAddNumbers is the function name. myIn01 and myIn02 are parameters. The values 3 and 6 are arguments passed into the function. return sends the answer back to the code that called it.
