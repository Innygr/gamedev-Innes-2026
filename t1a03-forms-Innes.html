t1a03 — Forms by Innes

HTML forms collect information from a visitor. This page demonstrates text fields, checkboxes, radio buttons, hidden values, file selection, buttons, textareas and select menus.

Reference: HTML Forms

1. Text input and labels

A label's for value should match the input's id. This makes forms easier to use.

2. Checkboxes

Checkboxes allow more than one selection.

3. Radio buttons

Radio buttons with the same name make a single-choice group.

4. Textarea and select menu

A textarea is for longer text. A select element provides a drop-down list.

5. Other form controls

The hidden input is not displayed like a normal field. It can store a value in a form, but it is not a secure place for secrets.

Output

Fill in the form and press the button.
