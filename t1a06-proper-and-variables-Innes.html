t1a06 — Proper Names and Variables by Innes

Variables store information so a program can use and change it. Good variable names make code easier to understand.

Reference: JavaScript Variables

Example variables

let myNum = 3;             // number
let myString = ' Hello ';  // string
let myFloat = 17.5;        // decimal number
let myBool = true;         // Boolean (true or false)

const myName = 'Innes';    // constant string

A variable name should describe the value it stores. JavaScript names are case-sensitive: myNum and mynum are different names. Use let when a value can change and const when it should not be reassigned.
