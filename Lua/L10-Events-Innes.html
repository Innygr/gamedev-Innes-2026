JavaScript → Luau

JavaScript event example:

document.getElementById("clickButton").addEventListener("click", function() {
    document.getElementById("eventOutput").textContent = "You clicked!";
});

Luau event-handling example:

local eventName = getEventName()
local eventValue = getEventValue()

if eventName == "click" then
    setEventOutput("You clicked!")
end

The browser detects the event in JavaScript and passes its name and value to Luau using bridge functions.
