What Are JavaScript Classes?

Good reference to JS classes

Classes are templates for creating objects. They can contain variables (called properties) and functions that work with those variables (called methods).

Classes connect to the topics of Objects and Functions.

A constructor() initializes each new object, while this refers to the particular object being used.

What Did We Learn?

  • Class: A template used to create objects.
  • Constructor: Sets up an object's initial properties.
  • Properties: Data stored inside an object.
  • Methods: Functions defined inside a class.
  • this: Refers to the current object instance.
  • new: Creates a new instance of a class.

Remember: a class defines the structure and behaviour; an instance is an individual object created from that class.
