The Mandelbrot Set

Every pixel represents a complex number called C. The fractal is generated by repeatedly applying this formula:

Zₙ₊₁ = Zₙ² + C

We begin with Z = 0. Each iteration squares Z and adds C. If the value grows beyond a magnitude of 2, the point escapes. The number of iterations it takes to escape determines its color.

Points that remain bounded are part of the Mandelbrot set and appear black.
