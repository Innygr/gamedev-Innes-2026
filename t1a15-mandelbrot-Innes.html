The Mandelbrot Set

Each pixel represents a complex number C. Starting at Z = 0, the renderer repeatedly calculates:

Zₙ₊₁ = Zₙ² + C

If the magnitude of Z grows beyond 2, that point escapes. How quickly it escapes determines its color. Points that remain bounded are part of the Mandelbrot set and appear black.
