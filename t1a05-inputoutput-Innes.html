t1a05 — Input / Output by Innes

JavaScript can read a value from an input and display a result in an HTML element.

Reference: innerHTML

Example code

const myIn01 = Number(document.getElementById('myNum01').value);
document.getElementById('myDiv01').textContent = 'Hi ' + myIn01;

The input's value is the input. Updating the output element is the output.
